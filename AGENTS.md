# Instructions for AI agents

The official Python library for the MAWAQIT API. Read
[CONTRIBUTING.md](CONTRIBUTING.md) first.

## Rules

- Never edit generated files, which start with `# Generated by
  codegen/generate.py`: change the spec in mawaqit/api-spec or the templates of
  `codegen/`, then regenerate.
- The spec is private: never copy it, or parts of it, into this repository.
- Coverage stays at 100%, mypy and pyright stay strict, and the public API
  stays 100% typed.
- Public names have Google style docstrings. Comments explain what the code
  cannot: keep them short.
- Supported Python versions: 3.10 to 3.14. Dependencies keep the lowest
  versions of `pyproject.toml` working; the CI tests them.
- Every change comes with tests, run against both clients with the `client`
  fixture.
